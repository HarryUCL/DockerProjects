1. 打开WindTerm，连接云服务器后，上传用于制作镜像的.java文件。方式是在命令行中输入rz，然后寻找到本机的.java文件即可。
2. 制作Dockfile。在和.java文件的同一文件夹下，制作Dockfile用于配置制作镜像要用到的代码。常用指令有：FROM，用于指定镜像基础环境；LABEL，用于自定义标签；EXPOSE，用于指定容器的暴露端口；COPY，复制.java文件到镜像; ENTRYPOINT,是容器固定的启动指令。
3. 执行如下命令：
docker run -d -p 8888:8080 myjavaapp:v1.0
即为制作镜像，容器化后用宿主机8888端口接收，此时可以用云服务器的对公IP地址的8888端口访问该容器服务。
